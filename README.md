# MyOrchestra

A Windows music player with glossy glass panels, 3D song cards, playlists, an equalizer, bass boost, customizable themes, and a floating mini-player.

## Download

Get the latest **MyOrchestra-Setup** installer from [Releases](https://github.com/KingToxic/MyOrchestra-Releases/releases/latest). Windows 10 or 11, 64-bit. Qt does not need to be installed separately.

Open the top-left logo menu for **Settings** and **Appearance**. Settings lets you choose the overlay shortcut and check for updates. Appearance includes the original Basic look, four colorways, and a Custom background and font.

Music files and playlists are kept on your device. Downloads do not contain sample songs or anyone else's library. Import your own audio to start.

This repository contains release downloads and their checksums. The application's source and personal iPhone builds are maintained separately. Open-source component notices are included with the installer.
